# 부산·울산·경남 분양·거래시장 통합 모니터 (estate-monitor)

사내 전용 모니터링 도구. 부산·울산·경남 39개 시·군·구 아파트 분양시장에서 미분양 급증 지역을
조기 포착해, 시공사 교체·분양 전략 변경 타이밍에 선제적으로 영업 접촉하기 위해
사용합니다.

## 판단 기준

인허가(공급) 동향과 미분양(수요 부진) 동향을 교차 분석해 지역을 세 그룹으로 분류합니다.

| 인허가 | 미분양 | 판단 |
|---|---|---|
| 증가 | 낮음 | 개발 기회 지역 |
| 증가 | 급증 | 공급 과잉 경보 |
| 감소 | 높음 | 위험 지역 |

## 기술 스택

Python 3.12 · Dash · Plotly · SQLite · SQLAlchemy · schedule · V-World(지도)

## 설치 및 실행

개발은 Windows(PowerShell), 배포는 Linux 서버 기준입니다.

```powershell
# Windows
venv\Scripts\activate
```

```bash
# Linux
source venv/bin/activate
```

```bash
pip install -r requirements.txt
```

`.env` 파일에 아래 API 키를 설정합니다.

```
MOLIT_APARTMENT_API_KEY=      # 국토부 아파트 매매 실거래가
MOLIT_APT_RIGHTS_API_KEY=     # 국토부 분양권전매 실거래가
MOLIT_OFFICETEL_API_KEY=      # 국토부 오피스텔 매매 실거래가
VWORLD_API_KEY=               # V-World 지도
VWORLD_DOMAIN=                # V-World API 서버 사이드 호출 시 domain 파라미터. V-World 콘솔에
                               # 등록한 도메인과 정확히 일치해야 함(포트 포함). 미설정 시
                               # "http://localhost:9090" 기본값 사용. 서버 배포 시 실제 접속
                               # 도메인(예: http://1.234.56.92:9090)으로 설정할 것.
BUILDING_PERMIT_API_KEY=      # 건축HUB 주택인허가 (배치 수집 + 대시보드 내 실시간 검색)
BUSAN_UNSOLD_API_KEY=         # 부산광역시 공동주택 미분양 현황
GYEONGNAM_UNSOLD_API_KEY=     # 경상남도 미분양 현황
CHEONGYAK_API_KEY=            # 청약홈 분양정보
HUG_PRICE_API_KEY=            # HUG 지역별 ㎡당 분양가격 (수동 실행 전용)
```

실행은 목적에 따라 4가지 모드를 지원합니다.

| 명령 | 동작 |
|---|---|
| `python main.py` | 대시보드 + 스케줄러 동시 실행 (운영 기본, 0.0.0.0:9090) |
| `python main.py --dashboard` | 대시보드만 실행 (개발) |
| `python main.py --scheduler` | 스케줄러만 실행 |
| `python main.py --update` | 데이터 즉시 1회 수집 후 종료 |

`--dashboard`에 `--debug`를 붙이면 Dash 디버그 모드로 뜹니다(`python main.py --dashboard --debug`).

대시보드 접속: http://localhost:9090
(V-World 지도 인증키가 이 도메인·포트로 등록되어 있습니다 — 아래 알려진 이슈 참고)

## 데이터 수집 API

| API | 대상 지역 | 수집 방식 |
|---|---|---|
| 국토부 실거래가 (아파트·분양권전매·오피스텔) 3종 | 부산·울산·경남 39개 시·군·구 | 배치 수집 (스케줄러, 최근 3개월) |
| 부산광역시 공동주택 미분양 현황 | 부산 16개 구·군 | 배치 수집 (스케줄러) |
| 경상남도 미분양 현황 | 경남 18개 시·군 | 배치 수집 (스케줄러) — 울산 미분양은 아직 수집기 없음 |
| 청약홈 분양정보 | 부산 | 배치 수집 (스케줄러) |
| 국토부 건축HUB 주택인허가 | 부산 | 배치 수집 (스케줄러, 구·군→동 순회) + 대시보드 내 실시간 검색 병행 |
| HUG 지역별 ㎡당 분양가격 | 부산 | 수동 실행 전용 — 스케줄러 미포함 |

## 대시보드 구성

탭 없이 위에서 아래로 스크롤하는 단일 페이지이며, 라이트모드로 고정되어 있습니다.

- **지역 선택 바** — 부산/울산/경남 드롭다운 + 구·군 드롭다운(선택 안 하면 지역 전체) +
  검색 버튼. 검색을 누르면 미분양·거래가·착공·허가 3개 섹션이 그 지역·구·군 기준으로
  다시 그려지고, 지도는 재요청 없이 해당 범위로 카메라만 이동하면서 선택된 지역만
  색칠됩니다.
- **🗺 지도** — V-World iframe 기반 행정구역 지도(부산·울산·경남 전체 상시 표시). 구·군을
  클릭하면 지도 아래 패널에 상세 정보가 뜹니다. 구·군/읍면동 경계 데이터는 서버가
  90일간 캐싱해 매번 V-World를 호출하지 않습니다(아래 알려진 이슈 참고).
- **🔔 미분양 알림** — 전월 대비 30% 이상 급증한 지역 자동 감지
- **📊 거래가 분석** — 구·군별 평균 거래가와 월별 추이
- **🏗 착공·허가** — 청약홈·건축HUB 기반 인허가 통계 + 건축HUB 실시간 검색
  (구·군/동 선택 후 조회, 상단 지역 선택 바와 무관하게 항상 부산 대상)

## 자동 갱신

매주 월요일 오전 7시 자동 갱신. 수집 대상은 실거래가(최근 3개월), 미분양 현황
(부산+경남), 건축인허가, 청약홈 분양정보입니다. HUG 분양가격은 스케줄러에 포함되지
않고 수동 실행 전용입니다.

## 알려진 이슈

- **V-World 지도 도메인 등록**: `http://localhost:9090`을 V-World에 도메인으로 등록해야
  지도·WMS 타일이 정상 표시됩니다. 접속 호스트·포트를 바꾸면 등록도 같이 바꿔야 합니다
  (자세한 인증 동작은 CLAUDE.md 참고).
- **구·군/읍면동 경계 캐시**: `dashboards/assets/geometry_cache/`에 90일간 캐싱됩니다.
  최초 요청(또는 캐시 만료 후 첫 요청)은 여전히 V-World 호출이 필요해, 그 시점에
  V-World가 503/한도초과 상태면 실패할 수 있습니다 — 이 경우 만료된 캐시가 있으면
  그걸 그대로 재사용하고, 캐시 자체가 없으면 지도는 WMS 폴백(클릭만 가능, 색칠 없음)으로
  동작합니다.
- **울산 미분양 미수집**: 미분양 수집기는 부산·경남만 있고 울산은 아직 없습니다.
  지도에서 울산 구·군을 선택해도 미분양 관련 수치는 비어 있습니다.
- **부산·울산 구·군명 중복**: 두 지역 모두 중구·남구·동구·북구가 있어, 지역(region) 태그
  없이 구·군명만으로 조회하면 두 지역 데이터가 섞일 수 있습니다.
- **건축HUB 배치 수집이 느림**: 시군구+법정동(필지) 단위로만 조회가 가능해 부산 전체를
  돌려면 동 단위로 수백 회 호출해야 합니다 — 그래서 대시보드에는 이와 별도로 구·군/동을
  직접 선택해 즉시 조회하는 실시간 검색도 함께 제공합니다.
